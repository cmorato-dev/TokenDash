Guía paso a paso para vincular Claude (se hace una sola vez)

Cada comando tiene su botón Copiar: pégalos en orden en una terminal del servidor (o por SSH). Si la cuenta es de otra persona, ella hace el paso 4. La misma guía está en docs/VINCULAR_CLAUDE.md.

  1. Entrar en el servidor y en la carpeta de TokenDash (la que contiene docker-compose.yml; cámbiala si no es ~/tokendash):
    ssh usuario@servidor-tokendash
    cd ~/tokendash
    Si docker responde permission denied, antepón sudo a los comandos.
  2. Ver si ya está vinculado. Si aparece "authMethod": "claude.ai", salta al paso 6.
    {{ claude_session.status_command }}
  3. Iniciar sesión. El terminal muestra una dirección que empieza por https://claude.com/cai/oauth/authorize y se queda esperando: no lo cierres. Copia la dirección completa (es larga; si se parte en varias líneas, únelas) y ábrela en el navegador.
    {{ claude_session.command }}
  4. Autorizar. En el navegador, entra con la cuenta de claude.ai, pulsa Autorizar y copia el código que muestra la página.
  5. Pegar el código en el terminal que esperaba y pulsar Enter. Debe aparecer Login successful. Pega solo el código, sin la dirección; si caduca, repite el paso 3.
  6. Comprobar y activar. Comprueba la sesión, activa la lectura en el servidor y actualiza la cuota en ese momento. Debe terminar con «Cuota de Claude actualizada en el dashboard».
    {{ claude_session.check_command }}
  7. Revisar aquí. Pulsa Comprobar ahora la sesión (abajo): debe decir «Sesión de claude.ai conectada». El dashboard mostrará Claude como Actualizado.

No uses claude setup-token: Anthropic limita ese token a enviar mensajes al modelo y no puede leer la cuota. Para desvincular el servidor: docker compose exec worker claude auth logout.
